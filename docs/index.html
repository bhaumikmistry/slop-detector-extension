What it actually does — and doesn't.

Measured against 20,000 real human tweets and 3,500 AI-generated tweets from seven models.

0.04% false positives on 20,000 real human tweets
~75% recall on marketing and essay register
0.2% recall when a model writes an ordinary tweet

This is not an AI detector. It finds slop register reliably and almost never accuses a human wrongly. It is blind to AI that writes casually — 97% of a 500-tweet set from a current model scored zero. The badge answers “does this read like slop?”, not “was this written by a machine?” The failures are published alongside the wins. Read the full evaluation →

Use the engine anywhere.

The scoring library is a separate package with zero dependencies. No model, no API calls — a few hundred regexes and a scoring curve, about 0.03ms per post. 

npm i @slop-detector/slop-detector
npx @slop-detector/slop-detector "your text here"

Also works as a CI gate: --fail-over 50 exits non-zero.
